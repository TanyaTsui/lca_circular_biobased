Submission settings

Submissions are sent to a Google Apps Script Web App attached to the workshop Google Sheet. Paste its URL here for this session (or set SUBMIT_URL in app.js). Leave it blank and Submit downloads a CSV instead.

Script for the receiving sheet (Extensions → Apps Script, then Deploy → New deployment → Web app, access: Anyone). It writes one row per input to a submissions tab and the comparison-chart values (all impact categories) to submission_results, one submission at a time, and confirms each save to the tool. After editing it, deploy a new version (Manage deployments → Edit → New version).
